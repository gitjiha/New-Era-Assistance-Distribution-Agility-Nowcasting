# New-Era-Distribution-and-Agility-Nowcasting
DAX UMPSA Project by IVY WITCH focusing on economic poverty in all 11 districts of Pahang. Since poverty rate in Pahang is only recorded on HEIS years (2020, 2022, 2024), this project extrapolated the missing years using PCHIP and nowcasted recent and upcoming poverty rate (ridge regression) and median income (regression tree).
